# Add safe mapped-register construction to declared transitions

This ExecPlan is a living document. The sections Progress, Surprises & Discoveries,
Decision Log, and Outcomes & Retrospective must be kept up to date as work proceeds.
If durable project context changes, update or create ADRs in docs/adr/ in the same change.


## Purpose / Big Picture

After this plan, an author using candidate Language 6 can keep a transition generated-owned,
declare its guard normally, and still construct a consumer-owned mapped register value. The two
new write-only forms are `initial`, which selects the target mapped declaration's checked initial
symbol, and `mapped(expression)`, which applies one target-declaration-owned, typed, versioned
unary lift. A transition can therefore clear a `MaybeTime`-like register or construct its
`Just markedAt`-like value without handing the guard and every update to an unrestricted
`EdgeBuilder` Hole.

The observable proof is a new compiled `keiro-dsl` conformance service with complementary guarded
siblings. Its generated transducer contains the declared `B.requireGuard` and `B.slot` lines,
uses `K.opaqueLit` for `initial` and `K.TApp1` for the declared lift, passes Keiki's sibling guard
verification, and reaches the same vertex and complete register file through forward execution,
encoded-event replay, and full replay. Mutation checks show that mixed Hole ownership remains
rejected, an unrecoverable command input remains rejected, a changed lift is caught by declared
cases, and a lift-version change moves fold identity and replay impact.

This implements the validated, narrowed form of
[IR-34](../improvement-requests/let-a-guarded-transition-write-a-mapped-register.md). It does not
make every mapped write newly legal: same-typed whole-value copies already work, and arbitrary
construction remains outside the language. It also does not relax
`AggregateTransitionOwnershipConflict` or add a partial `EdgeBuilder` callback.

## Surprises & Discoveries

- Observation: generated transitions already copy a whole mapped value when a command field and
  register have the same mapped type. The missing operation is construction, not mapped-register
  assignment in general.
  Evidence: `write currentArtifact := artifact` in
  `keiro-dsl/test/fixtures/consumer-types.keiro` scaffolds to a generated `B.slot` assignment.

- Observation: Keiki 0.9.1.0 already contains every execution primitive this feature needs.
  `TOpaqueLit` carries a value without a `Show` constraint, `TApp1` applies a pure Haskell unary
  function, and `USet` stores the result in one statically named slot. Update operands are not
  inverted; replay recomputes them after recovering the command.
  Evidence: `Term`, `Update`, `evalTerm`, `runUpdate`, `termReadsInput`, and the derived-term replay
  walkers in the released source at `mori://shinzui/keiki/packages/keiki`. Hackage and the
  upstream `v0.9.1.0` tag agreed at plan creation on 2026-08-21.

- Observation: Keiki's hidden-input analysis recursively traverses `TApp1`. Wrapping a command
  projection in a lift therefore does not hide the input read or make an unrecoverable command
  replay-safe.
  Evidence: `termReadsInput (TApp1 _ term) = termReadsInput term` in the released Keiki source.

- Observation: normal Hole code receives the complete `EdgeBuilder`; it can conjoin another
  guard and update arbitrary registers. Emitting the source guard before invoking that Hole would
  not preserve authoritative sibling coverage or write ownership.
  Evidence: `generatedOnCmdBlock` in `keiro-dsl/src/Keiro/Dsl/Scaffold.hs` and the builder
  operations in `mori://shinzui/keiki/packages/keiki`.

- Observation: Language 5 is now stable and published, and the active conformance-baseline schema
  deliberately removed `candidate-primary` after Language 5 publication. Activating Language 6
  therefore requires restoring that explicit candidate role rather than relabelling any stable
  Language-5 suite.
  Evidence: `keiro-dsl/src/Keiro/Dsl/LanguageVersion.hs`,
  `keiro-dsl/test/Keiro/Dsl/ConformanceBaseline.hs`, and
  [ExecPlan 263](263-publish-stable-keiro-dsl-language-5-and-close-the-blocker-review.md).

- Observation: Rei's motivating register was unobservable inside its Keiki aggregate and was not
  a snapshot seed. Rei's application state and projection independently derive the timestamp from
  the stored event. Dropping that register was correct, but the DSL limitation remains real for a
  future register that is read.
  Evidence: the audit recorded in IR-34 against
  `mori://shinzui/rei/plans/206-author-the-rei-service-workspace-at-keiro-dsl-language-5`.


## Decision Log

- Decision: Implement only target mapped `initial` and one declaration-owned unary lift; do not
  generalize all mapped expressions.
  Rationale: same-typed mapped copies already work. These two forms cover the reproduced clear/set
  shape while keeping the permanent language surface small and target-typed.
  Date: 2026-08-21

- Decision: Register the feature as candidate Language 6 with a new syntax profile and the same
  runtime-semantics profile as Language 5.
  Rationale: published Language 5 is immutable. The new expression is fold-visible only when used,
  so an unchanged aggregate upgraded from Language 5 to 6 need not acquire a global runtime fold
  segment.
  Date: 2026-08-21

- Decision: Use this exact source surface:

  ```text
  mapped opaque MaybeTime {
    haskell package=example module=Example.Domain type=MaybeTime
    codec = "example.MaybeTime.v1"
    version = "1"
    fixtures = "Example.Bindings.maybeTimeCases"
    initial = "Example.Bindings.noTime"
    write-lift from Time {
      function = "Example.Bindings.atTime"
      version = "1"
      fixtures = "Example.Bindings.atTimeCases"
    }
  }

  write dormantSince := initial
  write dormantSince := mapped(cmd.markedAt)
  ```

  Rationale: the outer declaration fixes the target and consumer package. One optional nested
  clause makes the lift unambiguous, keeps all hand-owned provenance together, and leaves the
  write expression free of module/package strings.
  Date: 2026-08-21

- Decision: Restrict the first lift source to one direct aggregate scalar: `Text`, `Int`,
  `Integer`, `Bool`, `Natural`, or `Time`.
  Rationale: those types already have total aggregate expression and generated Haskell lowering.
  The motivating `Time -> MaybeTime` case fits. Containers, `Json`, nominal types, and mapped
  sources would expand type/import/proof policy without a demonstrated need and can receive a
  later language feature.
  Date: 2026-08-21

- Decision: Treat `initial` and `mapped(...)` as complete write right-hand sides, not general
  expression atoms.
  Rationale: construction has a target type only at a write site. A dedicated `pWriteExpr` keeps
  guards, outcomes, rules, and nested arithmetic free of context-dependent meanings. Bare
  `initial` in Languages 1-5 retains its current ordinary-name resolution and diagnostics.
  Date: 2026-08-21

- Decision: Lower `initial` to `K.opaqueLit <qualified-initial>` and lower a lift to
  `K.TApp1 <qualified-function> <typed-source-term>` inside the generated `B.slot` assignment.
  Rationale: both are existing typed Keiki terms. Generated code continues to own the named slot,
  guard, event vector, mode, and target; the application can supply a value/function but cannot
  mutate the edge envelope.
  Date: 2026-08-21

- Decision: A lift function is pure and total by contract, carries a mandatory non-empty version,
  and carries a mandatory `NonEmpty (Text, source, target)` case symbol.
  Rationale: Haskell cannot prove totality or purity in the presence of bottoms and unsafe
  operations, and Keiro does not hash arbitrary source. The type boundary, finite executable
  evidence, explicit version, fold identity, and code review are the honest assurance available.
  Changing the body without changing the version remains a contract violation; tests must not
  claim universal automatic detection.
  Date: 2026-08-21

- Decision: Keep transition `BehaviorOwnership` as `GeneratedOwned`, while recording the
  consumer-owned lift function, version, and cases in mapping provenance and conformance.
  Rationale: the generated machine selects and invokes the declared function in exactly one
  declared write; the function cannot replace the guard or update a second slot. Calling the
  whole edge Hole-owned would discard truthful generated authority, while omitting lift
  provenance would hide hand-owned behavior.
  Date: 2026-08-21

- Decision: Never permit a normal `EdgeBuilder` Hole beside a declared guard or write.
  Rationale: mixed authorities would violate ADR 17 and could silently narrow the guard or modify
  another register outside canonical diff and fold identity.
  Date: 2026-08-21

## Context and Orientation

The owning package is `mori://shinzui/keiro/packages/keiro-dsl`, whose Cabal file is
`keiro-dsl/keiro-dsl.cabal`. It owns `.keiro` parsing, semantic checking, scaffold generation,
fold fingerprints, semantic diff, replay impact, and compiled conformance. No public runtime API
change belongs in `keiro-core` or `keiro`, and no dependency release is required. Keiki remains
the execution engine through the already-admitted `keiki >=0.9 && <0.10` bound.

A mapped type is a consumer-owned Haskell type described by a `.keiro` declaration. The raw AST
lives in `keiro-dsl/src/Keiro/Dsl/Grammar.hs`; mapped declarations are parsed in
`keiro-dsl/src/Keiro/Dsl/Parser/Mapped.hs`, rendered in
`keiro-dsl/src/Keiro/Dsl/PrettyPrint.hs`, and converted to a complete checked graph in
`keiro-dsl/src/Keiro/Dsl/TypeGraph.hs`. `StructuralDecl` and `OpaqueDecl` are the downstream
authorities. Add an optional `MappedWriteLift` to both rather than creating an aggregate-local
copy of the contract.

Aggregate transition expressions are parsed in
`keiro-dsl/src/Keiro/Dsl/Parser/Expression.hs` and resolved in
`keiro-dsl/src/Keiro/Dsl/Expression.hs`. Today `TypedScalarNode` contains literals, register or
command roots, mapped scalar projections, arithmetic, and predicates. `resolveWriteExpr` first
resolves the target register type, then checks the right-hand side against it. Introduce a
write-specific surface node for target initial selection and one for mapped lifting, and add
typed nodes that retain the checked target declaration, qualified symbol, lift version, source
type, and child expression. Do not teach `resolveScalarExpr` used by guards or outcomes to infer a
write target.

`keiro-dsl/src/Keiro/Dsl/Parser/Aggregate.hs` currently calls the general `pExpr` for every
`write`. Change only that clause to call a new `pWriteExpr`. Under Language 6, it recognizes the
whole-RHS spellings `initial` and `mapped(<ordinary scalar expression>)`; otherwise it delegates
to `pExpr`. In Languages 1-5, `initial` continues through the existing ordinary expression parser,
and `mapped(...)` is refused at its exact marker with `LanguageFeatureRequiresVersion`.

`keiro-dsl/src/Keiro/Dsl/LanguageVersion.hs` currently registers Languages 1 through 5, with
Language 5 as `Stable PublishedLanguage` and no candidate. Add version 6 as
`Candidate CandidateLanguage`, with predecessor 5, a new syntax profile containing
`MappedRegisterConstructionSyntax`, and the unchanged Language-5 runtime profile. Update
`keiro-dsl/test/Keiro/Dsl/FrontendProfiles.hs` to pin all registry rows and feature gates.
`keiro-dsl/test/Keiro/Dsl/FrontendCompatibility.hs` and its manifest continue to pin released
Languages 1-5.

`keiro-dsl/src/Keiro/Dsl/Scaffold.hs` resolves every generated transition once into
`ResolvedGeneratedTransition`. `renderKeikiTerm` produces the term placed on the right-hand side
of `B.slot`, while `generatedOnCmdBlock` keeps a Hole-owned edge separate. Extend the exhaustive
typed-expression walkers, Haskell import occurrence planning, and term renderer. An initial node
renders `K.opaqueLit` around the declaration's qualified initial. A lift node renders `K.TApp1`
with the qualified declared function and the recursively rendered source term. It must not render
an `EdgeBuilder` callback.

`keiro-dsl/src/Keiro/Dsl/StructuralConformance.hs` emits the one service-level module that checks
all mapped declaration evidence. Add lift imports and labelled assertions there. The declared
case symbol has the generated type expectation `NonEmpty (Text, source, target)`; every label must
be non-empty and unique, and every tuple must satisfy `function source == expected`. Extend the
create-once obligation and skeleton machinery in `keiro-dsl/src/Keiro/Dsl/ExplainBindings.hs` and
`keiro-dsl/src/Keiro/Dsl/Scaffold.hs` so a missing hand-owned module receives correctly typed
function and cases stubs exactly once.

`keiro-dsl/src/Keiro/Dsl/MappedConsumer.hs` records dependency modules and persisted mapping
identity. Add an optional lift identity containing source type, function, version, and cases to
both structural and opaque mappings. Keep its JSON schema backward-readable by decoding the new
field as optional; do not make old ledgers fail. `keiro-dsl/src/Keiro/Dsl/ScaffoldRun.hs` then
reports lift drift and imports the function/cases modules from the target declaration's consumer
package.

Persisted replay identity comes from `keiro-dsl/src/Keiro/Dsl/CanonicalEncoding.hs` and
`keiro-dsl/src/Keiro/Dsl/FoldFingerprint.hs`, not presentation text. Add canonical spellings only
for the new AST constructors, leaving every old constructor byte-identical. For a used lift,
`transitionSegment` must add a resolved length-delimited provenance segment containing target
mapped name, direct source type, qualified function, and lift version. The cases symbol is
evidence-only and does not change execution identity. An unused declared lift must not change an
aggregate fingerprint. The mapped initial symbol already participates in the mapped-register
segment; the new `initial` expression makes its use explicit in the transition segment.

`keiro-dsl/src/Keiro/Dsl/MappedDiff.hs` compares declaration metadata and
`keiro-dsl/src/Keiro/Dsl/Diff.hs` assigns compatibility consequences. Add
`MappedWriteLiftChanged` for add/remove/source/function/version changes and
`MappedWriteLiftFixturesChanged` for evidence-only case-symbol changes. The former always requests
a consumer rebuild; aggregate fold comparison and `keiro-dsl/src/Keiro/Dsl/ReplayImpact.hs` must
identify replay/snapshot impact only for aggregates whose transition actually uses the lift.
Changing only the cases symbol remains replay-neutral.

The compiled proof should be a new fixture at
`keiro-dsl/test/fixtures/mapped-register-construction.keiro`, generated output under
`keiro-dsl/test/conformance-mapped-register-construction/`, a new Cabal test suite named

## Validation and Acceptance

Acceptance requires all of the following observable behavior, not merely a successful build:

- The language registry reports Language 5 as stable and published and Language 6 as the sole
  candidate. Every released Language-1-through-5 fixture, diagnostic, canonical golden, and
  generated banner stays byte-identical. Under Language 5, bare `initial` retains its released
  ordinary-name behavior and `mapped(...)` fails at the feature marker with
  `LanguageFeatureRequiresVersion`; under Language 6, both new write forms parse and round-trip.
- `write dormantSince := initial` succeeds only when `dormantSince` is a mapped register whose
  checked declaration supplies an initial symbol. The generated assignment is equivalent to
  `B.slot @"dormantSince" =: K.opaqueLit Bindings.noTime`, remains inside the ordinary generated
  transition, and contains no `EdgeBuilder` Hole.
- A declared `write-lift from Time` accepts `mapped(cmd.markedAt)` only when the source expression
  checks as exactly `Time` and the target is the mapped declaration that owns the lift. Missing,
  duplicate, partial, invalid-symbol, unsupported-source, wrong-source, wrong-target, and

## Idempotence and Recovery

Parser, checker, pretty-printer, fingerprint, and test commands are read-only or deterministic and
can be rerun after any edit. Scaffolding is also repeatable: generated-owned files may be
regenerated, but consumer-owned bindings, lift implementations, case tables, and witnesses are
create-once obligations and must not be overwritten. Verify this explicitly with the second
scaffold invocation in Concrete Steps before accepting the feature.

The mutation driver must copy each file it changes into a directory created with `mktemp -d`,
install a trap before its first mutation, and restore the originals on success, failure, or
interrupt. It must finish by rerunning the green conformance test. If interrupted before the
trap is installed, inspect `git status --short` and restore only files named by the driver from
its temporary copies; never reset the worktree because unrelated user changes may be present.

There is no database migration. A service whose snapshot discriminator no longer matches must
discard the incompatible snapshot and perform full replay using its retained event history. Do
not rewrite events or weaken snapshot admission to recover from a changed lift version.

`just corpus-regen` is deterministic, but the corpus workflow may require a clean committed
baseline. Preserve unrelated work, including pre-existing plans, and commit or otherwise isolate
only this plan's implementation before retrying. If regeneration changes a published
Language-1-through-5 artifact, do not accept the bulk diff; locate and fix the accidental
current-language pointer, revert only the generated files owned by this work, and regenerate.

Stop and revise the plan before implementation continues if the design requires a new Keiki API,
a new global runtime profile, a relaxed `EdgeBuilder` ownership boundary, more than one lift per
target, a mapped/container/nominal lift source, or a change to released canonical bytes. Those
are larger compatibility decisions, not recovery tactics for this plan.
